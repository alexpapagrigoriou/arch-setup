Plug in the USB

Run:
lsblk

To confirm which is the USB:
lsblk -S

Output:
NAME   ...
sdX    ...
└─sdX1 ...

If MOUNTPOINTS is not empty run:
sudo umount /mnt/sdX1

Go to the ISO location

Example:
cd ~/Downloads

Check the ISO name:
ls

Write the ISO to the USB:
sudo dd if=<iso file> of=/dev/sdX bs=4M status=progress conv=fsync

Flush the USB:
sync

Eject the USB:
sudo eject /dev/sdX

Unplug the USB

---

Example for sda:

If MOUNTPOINTS is not empty run:
sudo umount /mnt/sda1

Go to the ISO location

Write the ISO to the USB:
sudo dd if=<iso file> of=/dev/sda bs=4M status=progress conv=fsync

sync

sudo eject /dev/sda
