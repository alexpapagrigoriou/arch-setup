Plug in the USB

Run:
lsblk

To confirm which is the USB:
lsblk -S

Output:
NAME   ...
sdX    ...
└─sdX1 ...

If MOUNTPOINTS is not empty run:
sudo umount /mnt/sdX1

Remove USB metadata:
sudo wipefs -a /dev/sdX
sudo sgdisk --zap-all /dev/sdX
(for sgdisk)
sudo pacman -S --noconfirm gptfdisk

Or completely wipe the USB:
sudo dd if=/dev/zero of=/dev/sdX bs=4M status=progress

Create a new partition:
sudo parted /dev/sdX mklabel gpt
sudo parted -a optimal /dev/sdX mkpart primary ext4 0% 100%

See the partition:
lsblk

Format the partition:

For Linux-only:
sudo mkfs.ext4 /dev/sdX1
sudo mkdir -p /mnt/usb
sudo mount /dev/sdX1 /mnt/usb
sudo chown -R $USER:$USER /mnt/usb
sudo umount /mnt/sdX1

For Linux and Windows:
sudo mkfs.exfat /dev/sdX1
(for mkfs.exfat)
sudo pacman -S --noconfirm exfatprogs

Eject the USB:
sudo eject /dev/sdX

Unplug the USB
